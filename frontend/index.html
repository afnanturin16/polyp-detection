Methodology

Three sequential decisions
1
Type — 512 px
hyperplastic / normal / adenoma
2
Architecture — 512 px
tubular vs. tubulovillous, adenomas only
3
Grade — 896 px
low vs. high dysplasia, adenomas only

CasLite reproduces this routing in a single shared MobileNetV3-Small encoder with three task heads.

Limitations

This is a research system trained on a single institution's data. Per-class performance is uneven, and weakest on the high-grade classes — the ones that matter most clinically. Gland segmentation marks glandular structure, not disease; Grad-CAM attention shows what influenced a prediction, not where pathology is. This tool is not a diagnostic instrument and must not be used to inform patient care.
